# グリモ最終企画 — きみのいる、小さな世界。

2026-09-07の依頼に基づく企画決定。視覚版は [HTML企画書](grimo-final-proposal.html)。旧3案の比較は調査履歴として残すが、本書とHTMLを今回の企画基準とする。今回は企画と説明用デモまで。製品への組込み・公開は次工程。

## 決めたこと

開けば、いつもの1匹が、専用の小さな世界で迎える。触れ方を変えると、返ってくる仕草も変わる。何もせず一緒に休む時間にも価値がある。

- 永久無料。広告、課金、ガチャ、スタミナ、日課、世話の失敗、親密度低下、期間限定の取り逃がしは作らない。
- 常に1グリモ＋専用世界。キャロル／ピノ／ジル／シュシュ／ムゥを初回から切替可能。切替中も複数体を重ねない。
- おやつ・小物は無制限の触れ合い道具。タスク達成、残数、成長段階に反応を紐付けない。未達の日も同じ内容で遊べる。
- 5体とも初回から豊かな反応を持つ。好みの触れ方や一緒に見た情景を端末内に覚え、仕草を選ぶ重みにだけ使う。放置による減少も、特定反応の永久ロックもない。
- グリモ画面だけ独立した、絵本のような可愛い世界。既存Grimoireの硬い配色を持ち込まず、文字サイズ・音・動きの抑制設定は尊重する。

追加質問は不要。提供絵を企画の外観基準に使う。名前は既存企画から引き継ぐ。[4体の原画](../assets/grimo/source/carol-pino-jill-shushu-canonical.jpg) と [ムゥの原画](../assets/grimo/source/muu-canonical.png) の比率と画風は提供画像のまま固定し、既存4体に揃えるための描き変えはしない。素材の原本・利用権・分離レイヤーの確認は、製品用の素材加工と配布に着手する前にまとめて行う。

## 世界と人格の基準

| 相棒 | 固定する外観 | 人格・動きの間 | 専用世界と触れるもの | 音の方向性 |
|---|---|---|---|---|
| キャロル | 紫と白の雲羊、月と星、茶色の耳と足、原画の顔と体型 | おっとり。接触はすぐ受け止め、毛→耳→体の順でゆっくり応える | 星眠りの雲床。月のクッション、星のモビール、雲の端が触れた方向へ沈む | 布の擦れ、柔らかな息、控えめな星の響き |
| ピノ | 青い水辺の獣、白いお腹、頭の毛、丸い手足、虹の泡 | 好奇心旺盛。目で追い、手が少し遅れて追いつく | 泡の浅瀬。貝の器、浮かぶ泡、小さな水輪。差し出した泡を抱える | 小さな水滴、泡がほどける音 |
| ジル | 葉の緑、黄緑の腹、小さい翼、尾、花と葉の装飾 | 元気だが穏やか。胸を張り、翼→尾に弾みが伝わる | 木漏れ日の苔の巣。葉の舟、木の実、花のつぼみ。尾に触れると葉が揺れる | 葉擦れ、苔への着地、控えめな羽ばたき |
| シュシュ | 桃色と白のパンダ、丸い耳、頭の花、瞳の花模様 | 甘え上手。こちらを確かめてから頬を寄せ、長く余韻を残す | 花びらの小庭。花の座布団、小さな花束、花びらの皿。花を差し出すと香りを楽しむ | 花びら、布、柔らかな鼻息 |
| ムゥ | 虹色の恐竜、虹の蝶ネクタイ、指揮棒、背中の小ピアノ。提供画像の比率・画風・外観を固定 | 穏やかな音楽家。相手のテンポを聴き、一拍置いて返す。演奏に正解・失敗・練習義務はない | 虹音の花丘。提供絵の夕空、虹の花、草原。指揮棒と小ピアノが触れ合いの場になる | 音OFFでも成立する頷き、尾の拍、花の揺れ。音を使う場合も控えめな演奏の気配 |

世界は遠景／中景／接地面／前景の4層。キャラクターの顔の周囲には余白を確保し、前景が目と指の接点を隠さない。装飾は触れ合いを受けて動くものを優先。昼夜差は照明の緩やかな変化に留め、夜にしか会えない反応は作らない。端末の時刻と別に好きな明るさを選べる。

## 触れ合いの設計

「圧」は対応端末以外では測れない。標準のタッチ・マウスでは接触時間、移動量、速度、方向、位置を使う。PCのhoverは視線追従、スマホでは画面内の指の移動／道具の接近を代わりに使い、画面の外の人の接近を検知すると約束しない。カメラ・マイクは不要。

| 入力 | 判別の初期仮説 | キャロル／ピノ／ジル／シュシュ／ムゥの返答 |
|---|---|---|
| つつく | 短い接触、移動小 | 耳がぴくり／小さく手を振る／胸を張る／小首をかしげる／小さく会釈する |
| ゆっくりなでる | 接触したまま滑らかに移動 | 毛に沈んで目を細める／手を添える／翼をほどく／頬を寄せる／指のテンポに頷く |
| 速くなでる | なでる速度が高い | ふわっと弾む／泡と遊ぶ／尾を振る／耳が弾む。痛がる・怒る反応なし／うれしく尾で拍を取る |
| 押して待つ | 接触を600ms前後維持 | 体重を預ける／指を両手で包む／掌に頭を置く／頬を寄せたまま休む／指揮棒をそっと下げ寄る |
| 離す | 接触終了 | 毛が戻る／手が名残を追う／尾が遅れて止まる／一度見つめ返す／一拍置いて穏やかに返す |
| 何度も触る | 接触の間隔・直近履歴 | 喜びの動きを小さく重ねる。アニメを先頭から毎回リセットせず、連打待ちの列を作らない／直前のテンポを聴き、一拍置いて返す |
| 道具を近づける・渡す | ドラッグまたは選択＋渡す | 香りを確かめる／両手で受ける／興味を示して近寄る／大切そうに抱える／おやつなら棒を休めて味わい、小物なら一拍置いて受け取る |
| 何もせず待つ | 操作なしで8〜20秒ほど | 眠そうに毛を整える／泡を見送る／葉を眺める／花に顔を近づける／静かに指揮し、虹の花が揺れる |

閾値は実機試遊で調整する。動かすたびに文字を出さず、顔・接点・姿勢が返事を担う。キーボードやドラッグが難しい人には「なでる」「そっと押す」「渡す」を選ぶ同等経路を用意する。

30秒の入口: 0〜3秒で目が合う → 触れた瞬間に局所反応 → 3〜12秒で相棒が動きを返す → 指を止めると寄り添う → 12〜30秒は呼吸と環境が続く。最後に評価・達成ダイアログを挟まない。いつ閉じてもよい。

## アニメーションとゲームフィール

原画のシルエット・顔・瞳・比率・色・装飾配置を基準画像と比較して固定する。頭／胴／左右の目とまぶた／口／耳／手足／毛・尾・翼／装飾を分離し、隠れていた部分は輪郭整合を確認する。瞬きを黒い楕円の上貼りで代用せず、原画に合う閉じ目が必要。

基本層は呼吸・瞬き・視線、反応層は接触部位・姿勢、余韻層は毛・尾・翼、環境層は光・水・葉。顔の形が変わる全身の過剰な拡縮はしない。入力直後の受け止め→短い意図の間→個性ある仕草→余韻へ接続する。重複入力は現在の姿勢から滑らかに遷移し、待機アニメの終了を待たせない。

初版の制作目安は各体8行為×3つの異なる反応核＋6つの自律行動、5体で150反応核。呼吸速度・視線位置・音量だけの違いを別反応として水増ししない。これは素材制作の目標であり完成数ではない。まずキャロルの3行為で外観と触感を検証し、合格した制作方法を5体へ広げる。目標数を満たしても不自然なら不合格。

直近の反応を避ける短い履歴と、その場の穏やかな気分（くつろぐ／遊びたい／興味）で選択を変える。状態は罰や拒否を生まない。単純な乱数で脈絡を消さず、視線や直前の接点から次の動きにつなぐ。

Web標準の画像レイヤー・CSS／Web Animationsを第一候補とし、1体の試作で変形と性能が不足した場合だけ描画方式を再評価する。実行時の画像生成・会話API・新規有料SDKは使わない。音は初期OFF、既存の適法な素材を確認できたものだけ採用。新規生成効果音や音楽は追加しない。振動も任意で、非対応時は見た目だけで完結する。

## 画面・データ・費用

中央の1匹に触ることが主操作。相棒切替、道具、音は小さな二次入口。数値メーター、常設の操作説明群、家具ショップ、日課一覧は置かない。UIは角丸0、キャラクター・自然物の丸い輪郭は保持する。

既存 `/plant` の入口と既存データは保持してから表示を移行する。製品実装時の新規保存は相棒選択・好み・減らない思い出に限定し、通貨やおやつ残高は新設しない。思い出は一意な識別子で重複を防ぐ。記録失敗でも触れ合いは続けられ、復旧案内を控えめに出す。IndexedDB追加・旧新バックアップ・互換版rollbackを検証し、植物やタスクの記録は削除しない。

制作・運用の追加費用は0円。既存環境と許諾済み素材で進め、課金API、試用登録、広告収益化は使わない。制作素材が不足しても外観を変えて穴埋めせず、未完成を明示して既存素材で検証可能な範囲を先に仕上げる。追加制作時間は必要であり、最高品質が無条件に成立するとは約束しない。

## 完成の判定

- 入力から最初の見える反応までp95で100ms以内を仮目標とし、初回・連打・低性能端末で実測する。60fps相当を目指すが、数字だけで合否を決めない。
- 60秒眺めても周期が露骨に揃わず、10回の同種入力で同じ演技を続けない。150反応核の目標と独立に、5体の個性が見分けられること。
- 原画との並列比較で顔・シルエット・比率・装飾の崩れがない。動作の頂点でも確認する。
- Chrome DevToolsで320／390／1280px、低い横画面、大文字、キーボード、タッチ、音OFF、reduced-motion、30分放置、復帰、連続入力を確認。非表示時の動作停止、console/network/runtime、保存とバックアップを検証する。
- 同意を得た協力者5名を目安に、うさぎしま等の参照作と同じ時間・操作条件で順番を入れ替えて試遊。「すぐ通じる」「反応の違いが自然」「眺めるだけでも生きている」「また触りたい」を聞く。参加謝礼や有料作品の新規購入は前提にしない。
- 初見5名中4名が10秒以内に触れ始め、主要4項目で参照作と同等以上を選ぶことを暫定ゲートとする。具体的な違和感が1件でもあれば原因を確認する。少数試遊で市場全体への優越を断定しない。協力者試遊前は「競合以上の品質を達成済み」と報告しない。

## 調査との接続

[追加調査](grimo-research-touch.md) の好評・大規模4作品を中心に、[既存10作品・37レビュー](grimo-proposals.md)を補助資料にした。重複を除く対象は12作品。総レビュー件数の新しい再集計はしていない。

主参照は[うさぎしま](https://play.google.com/store/apps/details?hl=en_US&id=com.pank0.usagishima)。手描きの相棒に、なでる・餌やり・ブラシ・遊ぶという行為で関わる構造が最も近い。固有キャラ、画風の模写、音、家具画像は借用しない。Finchは愛着、Pouは対象の明快さ、Talking Tom 2は入力から演技への接続を参照する。これらの説明に高度な入力認識の記載がないことを、機能が存在しない証明にしない。

調査上の「驚いて距離を取る」「探索からの帰還」「観察帳」は採用しない。触れ合いを求めた人が拒絶されたと感じる反応、相棒の不在、収集を埋める義務を避けるため。調査の示唆すべてを実装に持ち込まず、今回の明示方針を優先した。

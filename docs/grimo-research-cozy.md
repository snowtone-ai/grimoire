# グリモ：癒し相棒ゲーム調査

調査日: 2026-09-07 JST（公開ページを本文まで開いて確認）。対象は無料で閲覧できる公式サイト／App Store／Google Play。レビューは転載せず要約し、ストアに表示された投稿者名と日付を残した。ストアレビューは自己選択された少数標本で、全利用者の代表値ではない。

## 1. Neko Atsume（ねこあつめ）

公式機能: 庭にごはんとグッズを置いて待ち、40種以上の猫（特定グッズで現れるレア猫）を集める。来訪猫はCatbookに記録でき、写真をアルバム化・端末壁紙化できる。公式説明は[Google Play](https://play.google.com/store/apps/details?hl=en_US&id=jp.co.hit_point.nekoatsume)と[公式サイト](https://nekoatsume.com/en/)、グッズと仕草の説明は[公式ページ](https://nekoatsume.com/games/neko/enjoy/enjoy_goods.html)。

実レビュー（Google Play、取得日 2026-09-07）:

- **喜び — Sam H（2025-02-12）**: とても落ち着き、広告や課金を押しつけない。勝敗のために課金する必要がなく、応援のつもりで一度払ったと述べる。
- **不満 — Kaitlyn Abele（2026-05-13）**: 放置して戻れる点は楽しいが、機種変更後などに進行が2回消え、続編へ引き継げないと訴える。
- **喜び／要望 — Joy Gary（2026-03-22）**: 猫が庭に来て初めて贈り物をくれた体験を長く喜ぶ一方、英語翻訳の拡充を望む。

示唆: 「置く→離れる→予想外の来訪／贈り物を見る」の短い受動ループ、収集帳と写真を相棒の記憶として残す仕組みが強い。進行消失は癒し体験を一気に損なうため、グリモは端末内データのバックアップ／復旧導線を必須にする。

## 2. Usagi Shima（うさぎしま）

公式機能: 島を玩具・植物・建物で飾り、30種以上のうさぎを集める。餌やり、ブラシ、なでる、かくれんぼ、帽子、仲良しの証（keepsake）、写真アルバム、時間帯連動、縦横画面、オフライン、時間制限なし。機能一覧は[Google Play公式ストア](https://play.google.com/store/apps/details?hl=en_US&id=com.pank0.usagishima)。

実レビュー（Google Play、取得日 2026-09-07）:

- **喜び — Milo（2026-04-20）**: 可愛く楽しく、島拡張・所持枠拡張後に多くのうさぎと親友になれた。課金後も金のニンジンを集められる点を喜ぶ。
- **喜び — Hiblette Hibbard（2025-02-02）**: 1日1〜2回の訪問で足り、現実のお金なしでも島を可愛くできる「非侵入的」な設計を評価。
- **不満 — Meredith Boneske（2024-09-29）**: 癒されるが、1〜2分でやることが尽きる。待ち時間以外に遊べるミニゲームがもっと欲しいと要望。

示唆: ふれあいを「なでる／食べる／遊ぶ」の具体的な行為に分け、相棒ごとの好みと贈り物で関係を可視化する。グリモ4匹にも固有の好きな行動を持たせるが、毎日必須の世話や時間制限にせず、短時間で満足できる設計にする。島の飾り付けと写真は継続理由になる一方、空間不足・待ちだけの停滞を避ける。

## 3. Tsuki's Odyssey

公式機能: Mushroom Villageを自由に動くTsukiを定期的に見に行き、家を飾り、友だちを作り、釣りをする受動型アドベンチャー。Tsukiはプレイヤーの命令に従うペットではなく、世界を自分で動く存在と明記される。機能は[Google Play公式ストア](https://play.google.com/store/apps/details?hl=en_US&id=com.hyperbeard.odyssey)と[App Store](https://apps.apple.com/us/app/tsukis-odyssey/id1564146071)。

実レビュー（Google Play／App Store、取得日 2026-09-07）:

- **喜び — Grace Boeneman（Google Play、2026-05-08）**: 居心地、音楽、絵、自然な会話、季節イベント、少しずつ増える飾り場所を長所として挙げる。
- **不満 — Hello（Google Play、2026-04-11）**: 家や農場を埋めると新しい見出し・会話・収集が尽きる。購入特典の無料リロールが予告なくチケット制になったことも不信につながった。
- **不満 — Keith Leva（Google Play、2026-05-08）**: 雰囲気とキャラクターは好きだが、イベント以外のコンテンツが尽きて「content wall」に当たった。
- **喜び／不満 — edens a snake（App Store、2022-05-22）**: 季節ごとの模様替えと庭を愛する一方、ガチャ展示場所、報酬の重複、実績や郵便箱の意味不足を指摘。

示唆: 相棒が自律して動き、戻るたびに小さな発見がある表現はグリモ向き。会話・季節・飾りを足すときは、重複報酬、使い道のないUI、急な仕様変更を避ける。4匹を同時に動かし、低頻度の「今日は何をしている？」を核にするが、コンテンツの底が見えた後の観察マイルストーンを用意する。

## 4. Window Garden - Lofi Idle Game

公式機能: 室内庭園で植物を育て、部屋を飾り、新しい部屋を解放する。蝶・鳥などを集め、ミッション、ミニゲーム、月替わり季節、睡眠タイマーとlofi音楽を備える。公式説明は[開発元サイト](https://cloverfigames.com/index.html)と[Google Play公式ストア](https://play.google.com/store/apps/details?hl=en_US&id=com.cloverfi.windowgarden)。

実レビュー（Google Play、取得日 2026-09-07）:

- **喜び — Nessa（2024-12-04）**: ミニゲームと鳥・蝶で資源を得られ、強制購入や長い待ち時間がない。睡眠モードと内蔵音楽がストレス解消になると評価。
- **不満 — B E（2025-09-16）**: 進行、植物、装飾、曲、任意広告は好きだが、広告がストアや不審サイトを勝手に開くことがあると報告。
- **不満 — Blaze Woodward（2025-10-12）**: 可愛い雰囲気は好きだが、ミニゲームの資源効率・旅行価格に不満。ミニゲーム後のクラッシュでコインを失った経験もある。

示唆: 「眺める場所を自分で育てる」所有感と、睡眠・作業中に邪魔しない音をグリモに借りる。広告採用は前提にせず、通知・課金・世話を押しつけない。相棒や装飾が増えたときの表示密度、資源の使い道、クラッシュ時の報酬保全を最初から設計する。

## 横断結論（グリモ4匹への要件候補）

1. **短時間の受動観察を中心にする。** 来訪、自律行動、季節、小さな贈り物を入口にし、毎日達成しないと損をする世話にはしない。
2. **4匹それぞれに「好み・記録・変化」を持たせる。** 好きな遊び／餌／場所、仲良しの証、写真または観察帳を組み合わせる。集めるだけでなく、ふれあいが見えることが喜びになる。
3. **長期不満を先回りする。** 進行の消失、空間不足、重複報酬、仕様変更、クラッシュによる報酬消失、強制的な広告・課金を避ける。小さな追加コンテンツとバックアップ／復旧を用意する。

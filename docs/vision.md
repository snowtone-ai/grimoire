# vision.md (grimore-v2)

## Product promise

Grimoire v2 は、毎日のタスクを片付けるほど魔導書の生物と世界の発見が進む、
静かで長く使える local-first タスク管理アプリである。ゲーム的な報酬は行動を
支えるが、タスクを終える速さ、読みやすさ、データを失わないことを決して妨げない。

## Experience goals

- Home は「今日やること」だけを最短距離で扱える。完了済みは折り畳み、情報量を抑える。
- Calendar は月全体と日ごとの詳細を同一画面で往復できる。
- Grimo は UI を主張させず、生物と世界を鑑賞する余白を中心にする。
- Catalog は発見済みの生物・アイテムだけを博物誌として蓄積する。
- Settings はテーマ、音、動き、通知、Calendar、移行、export/import、起動紋章を管理する。
- 起動時は文字のない「魔導書の紋章」を既定で短時間表示し、完全OFF／一定時間／毎回を選べる。

## Trust promise

- 保存成功前に成功演出を出さず、失敗や未同期を黙って隠さない。
- タスク、繰り返し、報酬、成長は再試行・複数タブ・クラッシュでも二重適用しない。
- ブラウザ保存領域だけを「永久」とみなさず、永続ストレージ状態、容量、export、復旧手段を
  ユーザーに分かる形で用意する。自動削除は行わない。
- 旧版移行と将来の同期追加は、正本データを壊さない staging / adapter 境界で行う。
- 5年以上の利用と段階的な schema 更新を想定し、観測・診断・修復・退避を最初から設計する。

## Quality method

各縦断機能は「実装 → 実機・障害注入評価 → 目標との差分記録 → 一次資料、既存技術、
類似製品の失敗事例を再調査 → 差分を埋める再実装」を反復する。完了条件はコードの存在ではなく、
`docs/architecture.md` の品質基準内に差分が収まり、再現可能な証拠が残ることである。

## Non-goals for the first release

- SNS、共同編集、広告、ランキング、汎用 AI チャット。
- タスク本文を生物生成や外部解析へ送信すること。
- 自前サーバー同期を最初から抱えること。将来差し替え可能な port は定義するが、
  初期版は堅牢な端末内正本と明示的な Calendar 連携に集中する。

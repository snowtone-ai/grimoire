Re-encoding applied to every direct pack source (T044):

	ffmpeg -i <source> -af volume=<g>dB -ac 1 -ar 44100 -c:a pcm_s16le <out>

where <g> peak-normalises the file to -1.0 dBFS. The gain is per-file, measured
with ffmpeg's volumedetect, so all three vendored Kenney packs (these two plus
Interface Sounds in ../ui/) sit at one level and per-cue mixing can be done in
code instead of by ear. PCM s16le / 44.1 kHz / mono is the same
decodeAudioData-safe format ../ui/ already uses (Safari/iOS).

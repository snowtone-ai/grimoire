# anime/ — スプラッシュ・背景世界・BGM の素材置き場

ここへ動画（と、その静止画、エリアごとの BGM）を置くと、
`node scripts/sync-world-media.mjs` が `public/world/` と `public/audio/bgm/` へコピーし、
アプリが読む `public/world/manifest.json` を書き出します。
`pnpm dev` / `pnpm build` の前に自動で走ります（`package.json` の `predev` / `prebuild`）。

素材が 1 つも無い状態でもアプリは正常に動きます。その場合、世界はエリアごとの
グラデーション表現になり、スプラッシュは無文字の紋章表示になります（D-013）。

## ファイル名がそのまま仕様です

| ファイル名 | 用途 |
|---|---|
| `splash.webm` / `splash.mp4` | 起動時のスプラッシュ動画 |
| `splash.jpg` / `.png` / `.webp` | スプラッシュの静止画（動画が再生できない時に出る） |
| `area-01-coral-plateau.webm` / `.mp4` | 「陸珊瑚の台地」の背景動画 |
| `area-01-coral-plateau.poster.jpg` | その静止画 |
| `bgm-area-01-coral-plateau.ogg` / `.m4a` / `.mp3` | 「陸珊瑚の台地」の BGM・環境音 |

- 動画の名前（拡張子を除いた部分）は、`src/world/areas.ts` のエリア id と一致させてください。
  エリアを増やす場合は、先に `areas.ts` へ定義を追加します。
- 静止画は `<エリアid>.poster.<拡張子>` の形にします。
- BGM は `bgm-<エリアid>.<拡張子>` の形にします。接頭辞 `bgm-` が無いと動画として扱われます。
- 認識できない名前・拡張子のファイルは、コピーされずコンソールに一覧表示されます（黙って無視はしません）。

## 素材を用意する時の推奨仕様

ブラウザの制約と、モバイルでのバッテリー・通信量から決まる実務的な範囲です。

- **形式**: `.webm`（VP9 か AV1）と `.mp4`（H.264）の両方があるのが理想。片方だけなら `.mp4` が最も確実に再生されます。両方あると `.webm` が優先されます。
- **解像度**: 1920×1080 まで。縦持ちのスマートフォンでは中央を切り出して表示するため、画の主役は中央寄りに置いてください。
- **尺**: 10〜30 秒のシームレスループ。先頭と末尾がつながるように書き出すと、繰り返しが目立ちません。
- **容量**: 1 本あたり 8MB 以下を目安に。大きいほど初回表示が遅れます。
- **音声**: 不要です。ブラウザは音の出る動画を自動再生しません。音声トラックは削除してください（BGM は下の別項目で扱います）。
- **静止画**: 動画の 1 フレーム目と同じ絵にしておくと、切り替わりが分かりません。

## BGM を用意する時の推奨仕様

BGM はグリモ画面でだけ流れます（決定事項ログ F-13）。ホーム・カレンダー・設定は無音のままです。

- **形式**: `.ogg`（Vorbis / Opus）と `.m4a`（AAC）の両方があるのが理想。片方だけなら `.m4a` が最も確実です。両方あると `.ogg` が優先されます。
- **尺**: 1〜3 分のシームレスループ。フェードイン・フェードアウトはアプリ側で約 0.9 秒かけて行うので、素材側には付けないでください。
- **音量**: アプリ側で 34% まで絞って再生します。素材はピークが -3dBFS 程度に整っていれば十分です。
- **容量**: 1 本あたり 4MB 以下を目安に。
- **密度**: 低密度の環境音寄りにしてください。メロディが前に出る曲は、タスク管理の常用に耐えません。

素材が無いエリアでは、BGM 要素そのものが描画されません。設定の「BGMと環境音」を
ONにしていても、鳴らすものが無いだけで、エラーにはなりません。

## 動きを止める設定との関係

OS またはアプリの「動きを減らす」設定が有効な時、動画は読み込まれず静止画（または
グラデーション）だけが出ます。これは意図した挙動です（決定事項ログ E-5、WCAG 2.2.2）。
